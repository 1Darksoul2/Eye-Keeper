How it works

From words
to detections

Three steps. No training data, no labelling, no cloud, no API key.

01 / TYPE
✍️

Plain English input

Type anything while the video plays — literal terms like "car" or vague concepts like "dangerous items" or "someone using a phone". EyeKeeper figures out the rest.

02 / THINK
🧠

Semantic expansion

A sentence-transformer model maps your prompt to precise, detectable terms using embedding similarity and a curated concept taxonomy. No prompt engineering needed.

03 / SEE
🎯

Zero-shot detection

YOLO-World detects objects instantly — no retraining ever. Bounding boxes update the moment you press Enter, while the video keeps running.

Install & Run

Up in 60
seconds

Clone, install, and run. EyeKeeper starts serving on localhost:8000 with zero config.

# clone + install
git clone https://github.com/you/eyekeeper
pip install -r requirements.txt

# copy and configure env
cp .env.example .env
# edit .env with your keys

# start the server
python app.py
# → open http://localhost:8000
# run on a video file
# open playground, select Video mode
> person, car
> dangerous items
> ppe
> someone using a phone
# press Enter to update detection instantly
# run on an image
# open playground, select Image mode
# type what to detect, press Enter
> car, number plate
> fire hazard
> kids playing
# run on webcam (Live mode)
# open playground, select Live mode
# type while camera runs live:
> person
> someone using a phone
> suspicious behavior
Features

Built for real use

🧠

Semantic expansion

Sentence-transformer embeddings map vague prompts to concrete YOLO terms. Falls back to curated taxonomy matching if embeddings aren't installed — vague prompts still work either way.

🔬

Small object detection

SAHI-style sliced inference divides frames into overlapping tiles, catching small objects full-frame passes miss entirely. Cross-tile NMS removes duplicates cleanly.

🔄

Temporal tracking

IoU-based tracker propagates bounding boxes between inference frames. No flickering — smooth, stable boxes even at high frame-skip values on slower hardware.

⚡

Adaptive frame skip

Automatically adjusts inference frequency based on real-time GPU latency. Maxes out fast GPUs, stays watchable on CPU.

🚀

Three detection modes

Switch at runtime by pressing M. Fast for live webcam, Balanced for general video, Thorough for maximum accuracy on images or slow-moving scenes.
